# 公众号文字稿一键排版助手

## 1. 功能与适用范围

把**已经写好的文字稿**转换成**能直接粘贴进微信公众号编辑器的 HTML**。

适用：

- 用户有完整文字稿，只差排版
- 用户希望文章在公众号里看起来更专业、更有设计感
- 用户抱怨"排版太丑""样式粘贴后丢了""不知道用什么字体颜色"

不适用（不要答应）：

- 代写文章正文（只排版用户提供的文字）
- 生成图片长图、封面图
- 自动发布到公众号、自动上传图片
- 制作表格、SVG、交互动画（公众号支持有限）

## 2. 输入及文件格式

输入文件必须是 UTF-8 编码的 `.txt` 或 `.md`。

支持的结构写法：

| 写法 | 含义 |
|---|---|
| `# 标题` | 文章标题（也可以命令的 `--title` 传入） |
| `## 小标题` | 一级小节，自动编号 |
| `### 次级标题` | 小节内的小标题 |
| 空行 | 分段 |
| 单换行 | 段内换行（保留为 `<br>`） |
| `> 引用内容` | 引用块 |
| `- 列表项` 或 `* 列表项` | 无序列表 |
| `1. 列表项` | 有序列表 |
| `**加粗**` | 重点句 |
| `==关键词==` | 关键词高亮（点缀色下划线） |
| `` `代码` `` | 行内代码 |
| ` ``` ` 包围 | 代码块 |
| `---` | 分隔线 |

可选参数：

- `--style heytea | minimal | academic`
- `--title "标题"`
- `--author "作者名"`
- `--date "2026-10-23"`
- `--accent "#RRGGBB"`（替换点缀色）

## 3. 具体执行步骤

1. **确认输入**：检查文件存在、是 UTF-8、第一行有标题（或记下用户给的标题）。
2. **选风格**并说明理由：
   - 生活、品牌、活动、手账感、系列内容 → `heytea`（默认）
   - 散文、随笔、观点、书评 → `minimal`
   - 理工科、技术分享、实验记录、教程 → `academic`
3. **运行脚本**（在本 Skill 目录下执行）：

   ```bash
   python scripts/typeset.py <输入文件> --style <风格> --author "<作者>" --output <输出.html> --validate
   ```

   例如：

   ```bash
   python scripts/typeset.py ../../examples/sample-article.md --style academic --author "化工小张" --output ../../examples/output/sample-academic.html --validate
   ```

4. **读取命令输出**：
   - `排版校验：通过` → 进入第 5 步
   - `排版校验：未通过` → 按提示修复后重新运行，不得跳过校验
   - `错误：...` → 按提示处理（空文件、编码、标题缺失等）
5. **交付**：告诉用户双击 HTML 用浏览器打开，从上到下预览；确认后，在浏览器页面里从标题选到文末，复制，粘贴进公众号编辑器。
6. **可选调整**：用户想换点缀色时，加 `--accent "#RRGGBB"` 重新生成。

## 4. 输出格式与结果要求

- 单文件 HTML，所有样式写在元素的 `style` 属性里
- 无 `<style>`、无 `<script>`、无外链、无外部字体
- 容器 `max-width: 677px`（公众号正文宽度）
- 正文 16px，行高 1.85–1.95，正文对比度 ≥ 4.5:1
- 输出文件路径由 `--output` 指定；不指定时默认生成在输入文件旁边

## 5. 异常情况处理

| 情况 | 处理 |
|---|---|
| 文件为空或没有标题 | 命令返回错误；让用户补 `# 标题` 或使用 `--title` |
| 文件不是 UTF-8 | 提示用户用编辑器"另存为 UTF-8" |
| 风格名写错 | 命令列出可选风格；改用 `heytea` / `minimal` / `academic` |
| 校验失败 | 按失败项修复：外链、缺内联样式、对比度、字号行高 |
| 粘贴后样式丢失 | 确认是从浏览器**渲染后的页面**复制，而不是复制 HTML 源码 |
| 图片没有显示 | 本 Skill 不处理图片；图片需在公众号编辑器里手动插入 |

## 6. 使用限制

- 只排版用户提供的文字，不生成或改写正文内容
- 不支持图片、图床、封面图
- 不支持表格、SVG、动画、点击交互（公众号会过滤）
- 字体依赖读者设备，不同系统渲染略有差异
- 生成的 HTML 是静态近似，不等同于专业设计软件产出

## 7. 使用示例

输入文件 `examples/sample-article.md`：

```markdown
# 把「内耗」放回抽屉

白天担心明天，晚上复盘今天。
脑子像开了十个聊天窗口，一条也没回。
越是想停，越停不下来。
与其一直内耗，==不如做一场给情绪做减法的实验==。

## 第一步 · 写下来

把担心的那件事，写在纸上。**写下来的瞬间，它就小了一半。**

> 焦虑最怕被看见
```

执行：

```bash
python scripts/typeset.py ../../examples/sample-article.md --style heytea --author "化工小张" --output ../../examples/output/sample-heytea.html --validate
```

预期输出：

```text
已生成：.../examples/output/sample-heytea.html
排版校验：通过（7 项检查）
```

生成的页面特征：手机卡片式外框、米白纸底、纯黑页题眼词、阶梯式引言、水彩淡红圆环、手画圆圈编号、图钉手撕便签卡、文末"— 完 —"。
