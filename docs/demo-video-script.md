# 作品演示视频录制方案

由于开发环境无法完成真实屏幕录制和视频上传，本文件提供一份可以直接照着录制的方案。录完后由参赛者本人上传到视频平台，并把真实链接填入 `submission/submission-info.txt`。

## 一、录制目标

用 3–5 分钟真实展示：

1. 项目名称与用途
2. 要解决的真实问题
3. 输入数据（一篇文字稿）
4. 实际运行项目（命令行）
5. 输出结果（浏览器里的四套风格）
6. 喜茶风手账范本（同一篇内容的手工精排版展示）
6. 最终实现的功能与限制

原则：**只录真实运行结果，不剪辑出不存在的能力。**

## 二、录制前准备

### 需要打开的程序

1. 文件资源管理器：打开项目根目录 `wechat-article-typesetter`
2. 终端（PowerShell 或 Windows Terminal）
3. 浏览器（Chrome / Edge）
4. 录屏软件：OBS Studio，或 Windows 自带 `Win + G`（游戏栏）

### 窗口布局建议

- 左侧：终端，字号调大到 18–20px
- 右侧：浏览器，宽度约 800px
- 录制分辨率：1920×1080
- 提前把桌面无关文件、聊天窗口关掉

### 提前生成的页面（可选）

为了录制流畅，可以先运行一遍命令，确认三个 HTML 都能打开；录制时再重新运行一次，展示真实过程。

## 三、分镜与讲解词

### 镜头 1（0:00–0:25）项目名称与用途

**画面**：浏览器打开 README 或项目介绍文档首页。

**讲解词**：

> 大家好，这是我的参赛作品：公众号文字稿一键排版助手。
> 它解决的问题是：很多同学写完公众号文章后，排版要花一两个小时，做出来还不好看；好不容易排好，粘贴进公众号编辑器，样式又丢了。
> 这个工具可以把你写好的文字稿，一条命令变成能直接粘贴进公众号的 HTML。

### 镜头 2（0:25–0:50）展示输入数据

**画面**：文件资源管理器打开 `examples/sample-article.md`，或编辑器里展示全文。

**讲解词**：

> 输入是一篇普通的 Markdown 文字稿，里面有标题、小节、引用、列表、加粗和关键词高亮。
> 我不需要做任何设计，只需要保证文字内容写好。

### 镜头 3（0:50–1:30）实际运行命令

**画面**：终端，逐字输入或粘贴命令：

```powershell
cd C:\Users\yangbw\Desktop\claude-code\wechat-article-typesetter
python skill\wechat-article-typesetter\scripts\typeset.py examples\sample-article.md --style datawhale --author "化工小张" --output examples\output\demo-datawhale.html --validate
```

按下回车，展示输出：

```text
已生成：examples\output\demo-datawhale.html
排版校验：通过（7 项检查）
```

**讲解词**：

> 我运行这条命令，指定科技蓝分享会风、作者署名和输出路径，最后加上 `--validate` 做自动检查。
> 命令会生成一个单文件 HTML，并且检查 7 项排版质量：禁用标签、容器宽度、标题数量、外链资源、内联样式、文字对比度、字号和行高。
> 这里显示 7 项全部通过。

### 镜头 4（1:30–2:40）★ 重点展示：喜茶风手账版内耗文

**画面**：浏览器打开 `examples\showcase\neihao-heytea-handcrafted.html`，从封面**慢慢**滚动到结尾：封面（纸飞机小人）→「先做三次深呼吸」过渡页 → 实验背景（手绘箭头）→「实验分成三步」→ 便签纸「写下来」→ 拍立得「说出来」（热茶插画）→ 档案袋「放一放」→ 情绪减负勾选表 → 横线笔记本实验信息 → 彩蛋拍立得 → 互动结尾。每个页面停留 3–5 秒。

**讲解词**：

> 这是我最想给大家看的：同一篇内耗文做成的「白纸实验手账」——封面是简笔小人和飞走的纸飞机，过渡页让你先深呼吸，然后三步实验：便签纸「写下来」、拍立得「说出来」、档案袋「放一放」。
> 接着是情绪减负勾选表、横线笔记本式的实验信息页，最后是一个转发的彩蛋和评论区互动。
> 每一页都有一件手账道具、一幅简笔插画和一句手写批注，点缀色只有奶油黄一种。整篇像一本从手账本撕下来的实验记录。

### 镜头 5（2:40–3:20）同一篇文字稿，一键自动生成

**画面**：浏览器打开 `examples\output\demo-datawhale.html`，从标题滚动到文末。

**讲解词**：

> 刚才那篇是手工精排版范本；而同样的文字稿，用我们的工具一条命令就能自动生成——这是生成的科技蓝分享会风效果：浅灰白底、黑色大字块导语配黄色短横线，封面是粗黑大标题加蓝色横线，小节是蓝色英文小标签加黄色方块，清单是空心数字编号配虚线分隔，文末是黑色标签收尾。
> 所有样式都写在元素的内联 style 里，没有外部 CSS、没有脚本、没有外链，所以复制到公众号编辑器不会因为 class 丢失而变形。
> 手工范本展示设计上限，自动生成保证人人可用——这就是这个项目的完整能力。

### 镜头 6（3:20–4:00）多风格对比

**画面**：依次打开另外两个文件：

```text
examples\output\sample-minimal.html
examples\output\sample-academic.html
```

**讲解词**：

> 同一个 Skill 内置四套风格。刚才展示的是科技蓝分享会风，适合活动宣传；极简书卷风适合随笔和观点文，宋体标题、首行缩进、朱红细线。
> 学术理工风适合技术分享和实验记录，深蓝点缀、左侧竖线、浅蓝引用框。
> 换风格只需要改一个参数 `--style`。

### 镜头 7（4:00–4:30）自动化测试

**画面**：终端运行：

```powershell
python -m unittest discover -s tests -v
```

展示最后几行：

```text
Ran 17 tests in 0.172s

OK
```

**讲解词**：

> 项目带 17 个自动化测试，覆盖四套风格生成、排版检查、HTML 转义、空输入、错误参数、外链检出、低对比度检出和命令行端到端运行。
> 现在全部通过。

### 镜头 8（4:30–5:00）Skill 说明与限制

**画面**：打开 `skill/wechat-article-typesetter/SKILL.md`，展示 frontmatter 和"使用限制"部分。

**讲解词**：

> 项目以 Agent Skill 的形式交付。SKILL.md 说明了什么时候触发、输入格式、执行步骤和限制；真正的排版由 Python 脚本完成，所以结果稳定、可测试。
> 需要说明的是：它不代写正文，不支持图片和表格，最终粘贴效果仍建议在真实公众号后台确认。
> 项目使用 MIT 开源许可证，纯 Python 标准库，不需要安装任何第三方依赖。

### 镜头 9（5:00–5:15）结尾

**画面**：回到项目 README 或介绍文档。

**讲解词**：

> 以上就是公众号文字稿一键排版助手。谢谢观看。

## 四、录制后检查

- [ ] 视频里出现的命令都能在干净环境复现
- [ ] 终端输出是真实运行结果，没有剪辑拼接
- [ ] 页面滚动完整，四套风格和手账范本都出现
- [ ] 视频长度 3–5 分钟
- [ ] 画面清晰，字号可读
- [ ] 没有出现私人聊天、账号、密钥等信息
- [ ] 上传后把链接填入 `submission/submission-info.txt`

## 五、上传说明

1. 打开 B 站（bilibili.com）或腾讯视频，登录自己的账号
2. 上传视频，标题建议：`公众号文字稿一键排版助手｜第四届开放原子大赛赛道一`
3. 简介填写项目一句话介绍和代码仓库链接（上传仓库后补）
4. 发布后复制视频页面链接
5. 把链接交给比赛提交材料，**不要编造链接**

> 上传属于对外发布操作，必须由参赛者本人确认后进行。
